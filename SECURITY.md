# Security Policy

repoheat runs locally, makes no network requests, and only executes `git` with fixed arguments.

If you find a security issue (for example, a crafted repository that makes the HTML report run script), please **do not open a public issue**. Report it privately through [GitHub security advisories](https://github.com/ebxc-7s13/repoheat/security/advisories/new). You can expect a reply within a few days.

Only the latest release receives fixes.
