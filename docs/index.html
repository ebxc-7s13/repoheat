repoheat reads your git history and shows the hotspots: complex code that keeps changing. Any language, one command, nothing leaves your machine.

🔥 Hotspots

Files ranked by churn × complexity. The short list of places where refactoring pays off.

🗺️ Interactive heatmap

A zoomable treemap of your repo in a single offline HTML file. Export a PNG in one click.

🐛 Bug magnets

See which files keep attracting fix commits, so you know where tests are missing.

🚌 Bus factor

Spot hot files that only one person understands, before they go on holiday.

⇄ Hidden coupling

Files that always change together, even though nothing in the code says so.

🤖 Agent-ready

--md produces a summary for AGENTS.md or CLAUDE.md, so AI agents tread carefully in hot files.
